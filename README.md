# GAMEOVER VPS Hosting Bot

Premium Telegram-based VPS Bot Hosting Manager designed for deployment on Hugging Face Spaces (Docker) or local machines.

## 🚀 Features
- **Strict Sandbox Resource limits** (300 MB RAM limit, CPU hogging detection, 50 MB storage limit)
- **Auto-restart daemon** on bot crashes
- **Independent per-bot dependency installation** using `pip --target`
- **Full file manager** for hosted bots (Upload, Edit, Rename, Unzip)
- **Automatic DB backup and restore**
- **Robust Hugging Face anti-timeout shield** (Port 7860 web server)
- **Referral system and access slot management**
