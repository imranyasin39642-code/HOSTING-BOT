# TELEGRAM HOSTING MANAGER BOT (PYTHON)

## PROJECT GOAL

Build a Telegram Hosting Manager Bot in Python.

The bot will allow the owner to upload Telegram bot files directly through Telegram and manage multiple hosted bots from one central dashboard.

The system should work similarly to commercial Telegram hosting bots.

The owner wants to deploy and manage 10–12 Telegram bots without manually opening the hosting panel every time.

## UPLOAD SYSTEM

User uploads:

* .py file
* .zip file

Bot should:

1. Receive file
2. Create unique folder
3. Save file
4. Extract ZIP if needed
5. Verify main Python file exists
6. Register bot in database

Example:

/bots/bot_001/
/bots/bot_002/
/bots/bot_003/

---

## BOT REGISTRATION

When uploading:

Ask for:

Bot Name

Bot Token

Startup File

Example:

Bot Name:
Music Bot

Token:
123456:ABC

Startup File:
main.py

Save in database.

---

## START BOT

When Start is pressed:

System should:

* Check folder exists
* Check startup file exists
* Launch process

Example:

python main.py

Store:

* PID
* Start time
* Status

Database update:

Status = Running

---

## STOP BOT

When Stop is pressed:

* Kill process
* Save status

Database update:

Status = Stopped

---

## RESTART BOT

Restart sequence:

1. Stop process
2. Wait 2 seconds
3. Start process again

Update database.
